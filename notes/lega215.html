Module 1 Operating System

1 · Operating system vs. applications

An operating system (OS) is the program that manages all the activities on a computer — saving, printing, screen settings, keyboard/mouse settings, memory, and performance. It starts the computer and runs every other program. You don't type letters or draw in the OS itself.

An application is a program you use to get specific work done. The OS runs the applications.

Operating systemsApplications
Windows, macOS, Linux, Unix, MS-DOSWord, Excel, PowerPoint, Outlook, File Explorer, Paint, Media Player, Calculator
Multitasking

Windows runs several programs at once. Switch between them with ALT + TAB, or click the program's button on the taskbar (which shows what's currently active).

CheckIs Outlook an operating system or an application? What about Windows?
Outlook = application; Windows = operating system.

Windows is the OS that starts the computer and runs everything; Outlook is an email application that runs on top of it.

2 · The desktop & working with windows

Elements of the desktop

ElementWhat it is
DesktopThe background/workspace shown at start-up
Start button/screenLog in/out and open your most-used programs
IconsPictures that represent programs and actions
TaskbarAccess programs and settings; usually along the bottom or side
Notification areaShows what's running in the background
Date/TimeShould be kept current (can be reset)

Window techniques & controls

TechniqueDoes
MinimizeShrinks the window to the taskbar, app stays active
MaximizeFills the whole screen
RestoreReturns the window to its pre-maximized size
CloseCloses the window (ALT + F4)
Size / MoveDrag an edge/corner to resize; drag the Title Bar to move

Window parts: the Title Bar (names the program, holds the close button), Menu Bar (all commands), Toolbar (shortcuts to menu items), Status Bar (messages about what's happening), and the Workspace (where you do the work).

CheckYou want a window off your screen but still running so you can return to it. Minimize, maximize, or close?
Minimize.

Minimize reduces the window to the taskbar while keeping the application active. Close (ALT + F4) would quit it; maximize would make it full-screen.

3 · Dialog boxes, the Ribbon & menu conventions

Dialog box controls

  • Navigate with TAB (forward) and SHIFT + TAB (back).
  • Option (radio) buttons — pick one; the rest switch off. Check boxes — turn each on/off independently.
  • Spin boxes — arrows rotate through choices. Text boxes — type information. List boxes — reveal a list of choices.

The Ribbon

Tabs group related features; Groups gather related activities within a tab; Screen Tips pop up when you hover; a Dialog Box Launcher opens the full details for a group.

Menu conventions

SymbolMeaning
Check markFeature is on/off
Ellipsis (…)Opens a dialog with more choices
Triangular arrow ▸A submenu follows
Greyed-out itemNot available right now
CheckA menu item shows an ellipsis (…) next to it. What happens when you click it?
It opens a dialog box with more choices.

The ellipsis means "there's more to choose from." (A triangular arrow means a submenu; a greyed-out item isn't currently available.)

Mouse actions

Key keys

KeyDoes
ESCExit a menu or stop an action
BACKSPACEErases the character to the left of the cursor
DELETEErases the character to the right of the cursor
Function keys (F1–F12)Pre-assigned tasks (Help, Save…); combine with CTRL/ALT/SHIFT for more
CTRL · ALT · SHIFTModifier keys that "boost" other keys to trigger features
CheckYour cursor sits between two letters. Which key erases the letter to the right — BACKSPACE or DELETE?
DELETE.

DELETE erases to the right of the cursor; BACKSPACE erases to the left.

5 · Keyboard shortcuts (reference)

Worth memorizing — they make you noticeably faster:

ShortcutDoes
ALT + TABSwitch between open programs
ALT + F4Close an application window (or shut down)
CTRL + F4Close the active window/file
CTRL + ASelect all
CTRL + ESCOpen the Start menu
ESCCancel/get out of a procedure
SHIFT + F10Show the shortcut (right-click) menu for the selected item
F5Refresh the active window
TAB / SHIFT + TABMove forward / back through options
Windows keyOpen the Start menu
Windows + MMinimize all open programs (show desktop)
Windows + ROpen the Run dialog
CheckQuick: which shortcut selects everything, and which switches between open programs?
CTRL + A selects all; ALT + TAB switches programs.

(And ALT + F4 closes the current application — don't mix it up with CTRL + F4, which closes just the active file/window.)
